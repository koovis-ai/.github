# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in any Koovis AI repository, please
report it privately so we can address it before public disclosure.

**Preferred channel:** email [info@koovis.ai](mailto:info@koovis.ai) with
"Security:" in the subject line. Include:

- The affected repository and component
- A description of the vulnerability
- Steps to reproduce
- Your assessment of the impact
- Any suggested mitigation

**Please do not** open a public GitHub issue for security reports.

## Response expectations

- Acknowledgement within 3 business days
- Initial assessment within 7 business days
- Fix timeline depends on severity; critical issues prioritized

## Scope

Applies to all repositories under the `koovis-ai` organization on GitHub.

## Out of scope

- Social engineering
- Physical attacks
- DoS / DDoS reports on public-facing infrastructure
- Issues in third-party services we depend on (report to them directly)
