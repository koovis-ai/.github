# Koovis AI

**Koovis Studios**: original AI films and micro-series from Hyderabad.

Koovis AI Pvt Ltd is a film studio founded by Raj Kolachana. Its films, shorts and series are written and
performed by people and made with AI.

- [`koovis-ai-website`](https://github.com/koovis-ai/koovis-ai-website): the studio's site, [koovis.ai](https://www.koovis.ai)
- [`ci-shared`](https://github.com/koovis-ai/ci-shared): reusable GitHub Actions workflows
