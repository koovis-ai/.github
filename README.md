# .github

Organization-level defaults for [Koovis AI](https://github.com/koovis-ai):

- `profile/README.md` — rendered on the org's public page at
  [github.com/koovis-ai](https://github.com/koovis-ai)
- `SECURITY.md` — default vulnerability reporting policy (used by any repo
  without its own `SECURITY.md`)
- `.github/pull_request_template.md` — default PR template
- `.github/ISSUE_TEMPLATE/*.md` — default issue templates

Per-repo files override the defaults in this repo.
